# Βραχυχρόνια.ai: επέκταση για τη δήλωση ΑΑΔΕ

Επέκταση για Chrome και Edge (υπολογιστής). Όταν ανοίγει η φόρμα «Υποβολή Νέας Δήλωσης» στο
www1.gsis.gr, παίρνει από το Βραχυχρόνια.ai τις κρατήσεις που περιμένουν δήλωση και γεμίζει τη φόρμα
(με μία κράτηση αμέσως, με περισσότερες αφού διαλέξει ο χρήστης). Δεν πατά ποτέ υποβολή και δεν βλέπει
τους κωδικούς Taxisnet. Όταν ο χρήστης πατήσει «Υποβολή» και η ΑΑΔΕ δείξει μήνυμα επιτυχίας, σημειώνει την κράτηση
«Δηλώθηκε» (`/api/aade/declared`)· αν δεν φανεί μήνυμα, ρωτά τον χρήστη. Το «Επόμενη δήλωση» γεμίζει την επόμενη.

- `background.js` κρατά το κλειδί της σύνδεσης, ρωτά το `/api/aade/pending`, στέλνει το `/api/aade/declared` και τρέχει το `autofill.js` στη σελίδα.
- `aade.js` το πλαίσιο στη σελίδα της ΑΑΔΕ.
- `connect.js` η σύνδεση από τη σελίδα «Αυτόματη συμπλήρωση» της εφαρμογής (κουμπί «Σύνδεση επέκτασης»).
- `autofill.js` **παράγεται**: είναι το ίδιο script με τον σελιδοδείκτη (`property-manager/lib/aade-autofill.ts`).
  Μετά από αλλαγή εκεί: `cd property-manager && npm run build:extension` (ενημερώνει και την έκδοση στο manifest
  και φτιάχνει το `public/vrachychronia-extension.zip`). Το Chrome Web Store δεν επιτρέπει κώδικα που φορτώνεται
  από το internet, γι' αυτό το script είναι μέσα στην επέκταση και κάθε διόρθωση χρειάζεται νέα έκδοση στο store.

Δοκιμή: chrome://extensions → Developer mode → «Load unpacked» → αυτός ο φάκελος.
