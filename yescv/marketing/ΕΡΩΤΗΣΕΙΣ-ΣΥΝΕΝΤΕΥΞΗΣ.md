# Τι ρωτούν οι επαγγελματίες στις συνεντεύξεις του τουρισμού

Έρευνα Οκτωβρίου 2026 σε οδηγούς πρόσληψης για εργοδότες και υποψηφίους (Indeed, Glassdoor, Hcareers, Hogastjob,
TestGorilla, Instawork, Workable, SiteMinder, Talent Odyssey κ.ά.), στα αγγλικά, ελληνικά και γερμανικά.

**Πόσο αξιόπιστα είναι:** Οι πηγές είναι κυρίως sites καριέρας και εργαλεία πρόσληψης, όχι επίσημα πρότυπα. Οι λίστες
τους μοιάζουν πολύ μεταξύ τους. Αυτό λέει ότι οι ερωτήσεις είναι **πράγματι οι συνηθισμένες**, αλλά κάθε ξενοδοχείο
έχει το δικό του ύφος. Οι αναφορές του Glassdoor είναι εμπειρίες υποψηφίων, άρα ενδεικτικές. Πηγές στο τέλος.

Χρήση: (1) στην εφαρμογή, οι ερωτήσεις συνέντευξης που φτιάχνει η AI βασίζονται σε αυτές· (2) στη σειρά
«Η ερώτηση της εβδομάδας» (`ΠΕΡΙΕΧΟΜΕΝΟ.md`)· (3) στο live/webinar.

## 1. Τι ελέγχουν σχεδόν πάντα (σε κάθε θέση)

| Τι θέλουν να δουν | Πώς το ρωτούν |
|---|---|
| **Εξυπηρέτηση και ψυχραιμία με δύσκολο πελάτη** | «Πείτε μου για μια φορά που ένας πελάτης ήταν δυσαρεστημένος. Τι κάνατε;» |
| **Πίεση και προτεραιότητες** | «Πώς οργανώνεστε όταν όλα γίνονται μαζί (ουρά στο check-in, γεμάτο εστιατόριο);» |
| **Ομαδικότητα** | «Τι κάνετε όταν ένας συνάδελφος δεν βγάζει τη δουλειά του;» |
| **Πρωτοβουλία** | «Πότε κάνατε κάτι παραπάνω για έναν πελάτη;» |
| **Ακεραιότητα** | Σενάρια: «Βλέπετε συνάδελφο να παίρνει ένα μπουκάλι από το μπαρ» / «Υποψιάζεστε ότι πελάτης παίρνει αντικείμενα του ξενοδοχείου» |
| **Αξιοπιστία και διαθεσιμότητα** | «Μπορείτε βάρδιες, Σαββατοκύριακα, αργίες;» |
| **Κίνητρο** | «Πείτε μου για εσάς», «Γιατί εμάς;», «Γιατί να σας προσλάβουμε;» |

**Πώς απαντάς: η μέθοδος STAR**, με αληθινό παράδειγμα:
**Κ**ατάσταση (τι συνέβη) → **Σ**τόχος (τι έπρεπε να γίνει) → **Δ**ράση (τι έκανες *εσύ*) → **Α**ποτέλεσμα (πώς τελείωσε).
Οι οδηγοί συμφωνούν ότι οι συνεντευκτές **ψάχνουν λεπτομέρειες**. Ένα επινοημένο παράδειγμα διαλύεται στη δεύτερη ερώτηση.

## 2. Ανά θέση

### Υποδοχή / Front desk / Ρεσεψιόν
| Ερώτηση | Τι ελέγχει |
|---|---|
| Ένας επισκέπτης φτάνει και το δωμάτιό του δεν είναι έτοιμο / δεν του αρέσει. Τι κάνετε; | Ψυχραιμία, λύση μέσα στην πολιτική του ξενοδοχείου |
| Η κάρτα του επισκέπτη απορρίπτεται στο check-in. | Διακριτικότητα, διαδικασίες |
| Έχουμε overbooking ή διπλοκράτηση. | Προτεραιότητες, επικοινωνία με προϊστάμενο |
| Με ποια συστήματα κρατήσεων / PMS (π.χ. Opera, Fidelio) έχετε δουλέψει; Πόσο γρήγορα μαθαίνετε νέο σύστημα; | Άνεση με τεχνολογία, ειλικρίνεια |
| Πώς προτείνετε αναβάθμιση δωματίου χωρίς να πιέζετε; | Πωλήσεις με κρίση |
| Ουρά στο check-in και χτυπάει το τηλέφωνο. | Πολυδιεργασία |
| Ποιες γλώσσες μιλάτε; (συχνά δοκιμή στα αγγλικά ή γερμανικά επί τόπου) | Γλώσσα στην πράξη |
| Πώς προστατεύετε τα στοιχεία και την ιδιωτικότητα των επισκεπτών; | Εχεμύθεια, όρια ρόλου |

### Σέρβις / Σερβιτόρος / F&B
| Ερώτηση | Τι ελέγχει |
|---|---|
| Πόσα τραπέζια μπορείτε να εξυπηρετείτε ταυτόχρονα; | Ρεαλισμός, εμπειρία |
| Ένας πελάτης παραπονιέται για το φαγητό. | Αποκατάσταση, πότε φωνάζεις τον υπεύθυνο |
| Πώς συνεργάζεστε με την κουζίνα στο rush; | Επικοινωνία με το «πίσω μέρος» |
| Πελάτης με αλλεργία ή ειδική διατροφή. | Ασφάλεια, ακρίβεια |
| Πώς θα προτείνατε ένα πιάτο ή κρασί; | Πώληση χωρίς πίεση, γνώση μενού |
| Βλέπετε τραπέζι άλλης ζώνης να περιμένει. | Ομαδικότητα |
| Εμπειρία με POS και ταμείο; | Πρακτικές δεξιότητες |
| Μεγάλη παρέα, πολλές παραγγελίες. | Οργάνωση, ακρίβεια |

### Μπαρ / Bartender
| Ερώτηση | Τι ελέγχει |
|---|---|
| Φτιάξτε μας ένα Margarita / Old Fashioned / Mojito *(πρακτική δοκιμή)* | Κλασικές συνταγές, ταχύτητα, ακρίβεια στο jigger |
| Shake ή stir; Γιατί; | Τεχνική |
| Ένας πελάτης έχει πιει πολύ. | Υπεύθυνη διάθεση αλκοόλ, άρνηση εξυπηρέτησης |
| Πώς δουλεύετε στο rush με πολλές παραγγελίες; | Ροή, προτεραιότητες |
| Παράπονο για ένα ποτό. | Εξυπηρέτηση |
| *Συχνά ακολουθεί δοκιμαστική βάρδια.* | — |

### Housekeeping / Καμαριέρα
| Ερώτηση | Τι ελέγχει |
|---|---|
| Με ποια σειρά καθαρίζετε ένα δωμάτιο; Πόσα δωμάτια τη μέρα έχετε κάνει; | Μέθοδος, ρυθμός |
| Βρίσκετε προσωπικά αντικείμενα επισκέπτη / χρήματα. | Τιμιότητα, διαδικασία «απολεσθέντων» |
| Βρίσκετε κάτι επικίνδυνο στο δωμάτιο. | Ασφάλεια, αναφορά |
| Ο επισκέπτης είναι μέσα και το «Μην ενοχλείτε» είναι κρεμασμένο όλη μέρα. | Ιδιωτικότητα, κρίση |
| Χημικά καθαρισμού: τι προσέχετε; | Ασφάλεια |
| *Για υπεύθυνη ορόφου:* πώς κρατάτε σταθερό το επίπεδο καθαριότητας στην ομάδα; | Επίβλεψη, εκπαίδευση |

| Πώς αποθηκεύετε σωστά τα τρόφιμα; Πώς ελέγχετε θερμοκρασίες; | Υγιεινή |
| Πώς χειρίζεστε τα αλλεργιογόνα; | Ασφάλεια πελάτη |
| Συνάδελφος παραβιάζει κανόνα υγιεινής. | Ακεραιότητα |
| Ο σεφ σας ζητά ένα πιάτο που δεν έχετε φτιάξει, μέσα στο service. | Ψυχραιμία, μάθηση |
| Πώς δέχεστε την κριτική; | Συνεργασία |
| *Συχνά ζητούν δοκιμή (κόψιμο, βασική παρασκευή).* | — |

### Guest relations / Concierge
| Ερώτηση | Τι ελέγχει |
|---|---|
| Πώς υποδέχεστε έναν επισκέπτη που μόλις έφτασε; | Πρώτη εντύπωση, ζεστασιά |
| Πού θα στέλνατε μια τετραμελή οικογένεια για φαγητό; *(αναφέρθηκε σε συνέντευξη Four Seasons)* | Γνώση περιοχής, προσωπική εξυπηρέτηση |

## 3. Ειδικά για τη σεζόν

Οι οδηγοί πρόσληψης για εποχικό προσωπικό δίνουν βάρος σε **διαθεσιμότητα για όλη τη σεζόν, αξιοπιστία, ψυχραιμία στην
αιχμή και γρήγορη προσαρμογή**. Η ερώτηση για τις ημερομηνίες είναι νόμιμη, γιατί αφορά τη δουλειά.

- «Μπορείτε από [ημερομηνία] έως [ημερομηνία], χωρίς διακοπή;» → **Δώσε ακριβείς ημερομηνίες.** Ένα «μάλλον» είναι κόκκινη σημαία.
- «Μπορείτε 6 μέρες τη βδομάδα / διπλοβάρδιες στην αιχμή;»
- «Θα μείνετε μέχρι το τέλος της σεζόν, και τις τελευταίες βδομάδες;»
- «Έχετε ξαναδουλέψει σεζόν; Γιατί φύγατε / γιατί δεν γυρίσατε;»
- «Πώς θα έρχεστε στη δουλειά;» / «Χρειάζεστε διαμονή;»

**Τι να ρωτήσει ο υποψήφιος για τη διαμονή** (από οδηγούς για εργαζόμενους σεζόν): απόσταση από τη δουλειά, αν
κρατιέται από τον μισθό και πόσο, αν περιλαμβάνονται γεύματα, Wi-Fi, πλυντήριο.

## 4. Ερωτήσεις που ο εργοδότης δεν πρέπει να κάνει

Ελληνικές νομικές και επαγγελματικές πηγές, με βάση τον **ν. 4443/2016 για την ίση μεταχείριση**, αναφέρουν ότι δεν
πρέπει να ρωτούν για:
**οικογενειακή κατάσταση, παιδιά ή σχέδια για παιδιά, εγκυμοσύνη, υγεία ή ιατρικό ιστορικό, θρησκεία, πολιτικές πεποιθήσεις, ηλικία.**

- Ο υποψήφιος **μπορεί ευγενικά να μην απαντήσει**: «Δεν νομίζω ότι επηρεάζει τη δουλειά. Μπορώ να σας πω για τη διαθεσιμότητά μου».
- Τι μπορούν να ρωτήσουν νόμιμα: αν είσαι διαθέσιμος/η τις ημερομηνίες και τις βάρδιες που απαιτεί η θέση.
- Κάποιες νομικές πηγές μιλούν και για «δικαίωμα στο ψέμα» σε τέτοιες ερωτήσεις. **Δεν είναι παγιωμένο**, οπότε δεν το προτείνουμε.
- Για καταγγελία: Συνήγορος του Πολίτη (φορέας ίσης μεταχείρισης) ή Επιθεώρηση Εργασίας. *Επιβεβαίωσε τα στοιχεία επικοινωνίας πριν τα δημοσιεύσεις.*

> Δεν είναι νομική συμβουλή. Πριν γίνει δημόσια ανάρτηση, το ακριβές κείμενο ελέγχεται στον νόμο.

---

## 5. Ερωτήσεις που κάνει ο υποψήφιος στο τέλος

Οι οδηγοί προτείνουν: ετοίμασε **5**, κάνε **2–3**, αφού πρώτα σου περιγράψουν τη θέση. Μη ρωτάς ό,τι γράφει το site τους.

- «Πώς μοιάζει μια συνηθισμένη μέρα / βάρδια σε αυτή τη θέση;»
- «Υπάρχει εκπαίδευση πριν ξεκινήσει η σεζόν, π.χ. στο σύστημα κρατήσεων;»
- «Τι σας αρέσει περισσότερο στο να δουλεύετε εδώ;»
- «Πώς είναι η ομάδα με την οποία θα δουλεύω;»
- «Υπάρχει δυνατότητα να επιστρέψω την επόμενη σεζόν ή να εξελιχθώ;»
- «Γιατί είναι ανοιχτή η θέση;» *(αν ο προηγούμενος προήχθη, καλό σημάδι)*

---

## 6. Τα λάθη που αναφέρουν οι οδηγοί

- Καμία έρευνα για το ξενοδοχείο.
- Αρνητικά λόγια για προηγούμενο εργοδότη.
- Γενικόλογες απαντήσεις χωρίς παράδειγμα. Οι εργοδότες το βλέπουν ως **κόκκινη σημαία**, όπως και την έλλειψη ζεστασιάς.
- Άρνηση βαρδιών ή ασαφής διαθεσιμότητα.
- Αμελημένη εμφάνιση.
