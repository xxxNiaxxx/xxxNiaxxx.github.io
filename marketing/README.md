## Facebook / Instagram (πληρωμένη διαφήμιση ή post σελίδας)

**Κύριο κείμενο**
```
Έχετε Airbnb ή Booking; Δείτε όλες τις κρατήσεις σε ένα ημερολόγιο, πόσα σας μένουν καθαρά και τη δήλωση στην ΑΑΔΕ έτοιμη.
Δωρεάν μέχρι το τέλος του 2026.
```
**Τίτλος** (έως 40 χαρακτήρες): `Γλιτώστε χρόνο με το Airbnb/Booking`
**Περιγραφή**: `Για Έλληνες οικοδεσπότες`
**Κουμπί**: «Εγγραφή» ή «Μάθετε περισσότερα»

**Στόχευση (πρόταση):** Ελλάδα, 28–65, ενδιαφέροντα «Airbnb», «Booking.com», «Ενοικιαζόμενα δωμάτια»,
«Τουρισμός», «Ιδιοκτησία ακινήτων». Ξεκινήστε με 5 €/ημέρα για μία εβδομάδα και δείτε πόσες εγγραφές φέρνει.

## Απαντήσεις σε σχόλια

Δύο κανόνες: **πρώτα βοηθάτε, μετά μιλάτε για την εφαρμογή**, και **σε ξένες ομάδες χωρίς link**
(το στέλνετε σε προσωπικό μήνυμα, αφού το ζητήσουν). Απαντάτε μέσα στην ίδια μέρα. Η στρατηγική
πίσω από αυτά είναι στο [`STRATEGY.md`](STRATEGY.md).

### Στη δική σας σελίδα ή στη διαφήμιση

**«Ενδιαφέρομαι» / «Πώς λειτουργεί;»**
```
Ευχαριστώ πολύ! 😊 Ανεβάζετε το αρχείο κρατήσεων της Booking/Airbnb και βλέπετε αμέσως πόσα σας μένουν καθαρά και τη δήλωση της ΑΑΔΕ έτοιμη. Σας στέλνω μήνυμα με τον σύνδεσμο!
```

**«Πόσο κοστίζει;»**
```
Είναι δωρεάν μέχρι το τέλος του 2026, χωρίς κάρτα. Από το 2027 κοστίζει 12 € τον μήνα για κάθε κατάλυμα. Μπορείτε να σταματήσετε όποτε θέλετε και να πάρετε μαζί όλα σας τα στοιχεία.
```

**«Έχω λογιστή, δεν το χρειάζομαι»**
```
Πολύ σωστά, ο λογιστής χρειάζεται! Η εφαρμογή δεν τον αντικαθιστά. Σας γλιτώνει τη συλλογή των στοιχείων κάθε μήνα και του τα δίνετε έτοιμα σε ένα αρχείο. Οι περισσότεροι λογιστές το εκτιμούν πολύ 🙂
```

**«Είναι ασφαλή τα στοιχεία μου;»**
```
Τα δεδομένα αποθηκεύονται σε servers στην Ευρώπη (Φρανκφούρτη), με κρυπτογράφηση και πλήρη συμμόρφωση με τον GDPR. Δεν μοιραζόμαστε τίποτα με κανέναν, και μπορείτε να τα κατεβάσετε ή να τα διαγράψετε όποτε θέλετε.
```

**«Έχω iPhone»**
```
Λειτουργεί κανονικά από τον browser του iPhone (Safari), χωρίς εγκατάσταση. Η εφαρμογή για Android έρχεται σύντομα στο Google Play.
```

**«Υπάρχει ήδη το [άλλο πρόγραμμα]»** (ποτέ μην κατηγορείτε τον ανταγωνιστή)
```
Ναι, υπάρχουν καλά προγράμματα! Αυτό εδώ το έφτιαξα ως οικοδέσποινα για τα δικά μας ελληνικά: ΑΑΔΕ, ΤΑΚΚ και τι κρατάει πραγματικά η Booking. Δοκιμάστε το δωρεάν και δείτε αν σας ταιριάζει.
```

**Αρνητικό ή ειρωνικό σχόλιο** (μία ήρεμη απάντηση και τέλος)
```
Ευχαριστώ για τη γνώμη σας! Αν θέλετε, πείτε μου τι θα σας ήταν χρήσιμο, γιατί η εφαρμογή βελτιώνεται συνέχεια με βάση όσα μας λένε οι οικοδεσπότες.
```

### Σε ομάδες οικοδεσποτών (απάντηση σε ερώτηση άλλου)

Μόνο η χρήσιμη απάντηση, π.χ.:
```
Η Booking κρατάει, εκτός από την προμήθεια, και χρέωση πληρωμής περίπου 1,6% όταν πληρώνει εκείνη τον επισκέπτη. Το ΤΑΚΚ που εισπράττει δεν είναι έσοδό σας. Γι' αυτό η κατάθεση βγαίνει λιγότερη απ' ό,τι περιμένετε.
```
Αν ρωτήσουν «πώς το βρήκες;» / «με τι τα παρακολουθείς;»:
```
Έφτιαξα ένα εργαλείο για το δικό μου κατάλυμα που τα υπολογίζει αυτόματα. Σου στέλνω μήνυμα αν θες να το δεις 🙂
```

```
Γεια σας! Είμαι η Δήμητρα, κι εγώ οικοδέσποινα (Serene Vintage). Εδώ μπορείτε να γραφτείτε δωρεάν: https://aivrachychronia.vercel.app/waitlist
Αν θέλετε να το δείτε πρώτα χωρίς εγγραφή, υπάρχει και λογαριασμός δοκιμής. Ό,τι απορία έχετε, γράψτε μου εδώ!
```

Μετά από 4–5 μέρες, αν δεν απάντησε:
```
Γεια σας ξανά! Προλάβατε να ρίξετε μια ματιά; Αν θέλετε, σας δείχνω σε 5 λεπτά από το τηλέφωνο πώς βγαίνει η δήλωση του μήνα.
```
